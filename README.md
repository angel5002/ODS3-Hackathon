# ODS3-Hackathon — recuperar citas perdidas

Prototipo para CientíficaHack 2026 (Desafío 4, ODS 3). Estima el riesgo de que cada cita de mañana no se atienda, envía recordatorios simulados, llama con un agente de voz a quienes no responden y propone pacientes de la lista de espera para los cupos que se liberan. Una persona decide cada reasignación.

> Pacientes ficticios. Citas y modelo basados en datos abiertos reales del Hospital María Auxiliadora (2023).

En construcción. Instrucciones completas al cerrar la ejecución 1.

## Atribución del dataset

"Citas médicas en el Hospital de Apoyo María Auxiliadora - [HMA]", Hospital de Apoyo María Auxiliadora, publicado en la Plataforma Nacional de Datos Abiertos del Perú bajo la licencia Open Data Commons Attribution (ODC-BY).
